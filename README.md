# Firmware Engineering باللغة العربية

هذا المشروع ليس مجرد مشروع AVR.

هدفه تعليم كيفية التفكير وكتابة Firmware احترافي من خلال بناء مشروع حقيقي خطوة بخطوة.

كل فصل يحتوي على:

- شرح الفكرة
- لماذا نستخدمها
- الأخطاء الشائعة
- التطبيق العملي
- الكود النهائي

لا تحتاج إلى خبرة سابقة في Firmware، لكن يفضل معرفة أساسيات لغة C.
