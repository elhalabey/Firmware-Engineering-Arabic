# لماذا Firmware Engineering؟

## مرحبًا بك

هذا الكتاب ليس لتعليم لغة C.

وليس لتعليم AVR فقط.

هدف هذا الكتاب هو تعليم طريقة التفكير التي يستخدمها مهندس الـ Firmware عند بناء نظام Embedded حقيقي.

سنبني مشروعًا صغيرًا خطوة بخطوة.

لكن الهدف الحقيقي ليس المشروع.

الهدف هو تعلم كيف تكتب Firmware يمكن فهمه وصيانته وتطويره بعد سنوات.

إذا تعلمت طريقة التفكير...

ستستطيع العمل على:

- AVR
- PIC
- STM32
- ESP8266
- ESP32

لأن المبادئ واحدة.

الذي يتغير هو أسماء الـ Registers فقط.

- Firmware ليس مجرد كود.
- تنظيم المشروع أهم من سرعة كتابته.
